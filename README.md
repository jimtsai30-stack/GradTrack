# GradTrack

長庚大學資訊管理學系（112學年度入學）畢業學分規劃與進度追蹤工具。

**線上使用**：https://jimtsai30-stack.github.io/GradTrack/gradtrack.html

## 這是什麼

一個單一 HTML 檔案的畢業學分規劃工具，不需要安裝、不需要帳號、不需要網路連線（下載後可離線使用）。打開就能：

- 依照系上課表勾選已修課程，即時計算學分進度
- 查看畢業學分四大分類（管院共構必修、系訂必修、系選修、通識）的完成狀況
- 檢查系選修「系內至少27學分＋外系至多12學分」、通識各子領域（英文/核心/多元）等細項畢業規則是否達成
- 列出尚未修完的必修課程
- 貼上教務系統匯出的修課紀錄，一鍵自動勾選比對成功的課程

## 使用方式

直接打開上面的線上連結即可。想要離線使用的話，下載 `gradtrack.html` 這個檔案，用瀏覽器開啟即可運作。

## 資料存放方式

所有勾選紀錄只存在使用者當下瀏覽器的 localStorage 裡，不會上傳到任何伺服器。不同人打開同一個連結，彼此的勾選進度完全獨立、互不可見；同一個人換裝置或換瀏覽器，也不會同步。

## 資料來源與已知限制

- 系課表：`Curriculum_BS112_20260420.pdf`（112學年度入學適用）
- 通識課表：112學年度第一學期通識課程表（僅涵蓋該學期的多元選修開課清單）
- 核心課程每科3學分、多元選修每科2學分為課表載明之標準學分數；少數微學分課程與特殊課程學分已個別標示
- 通識多元選修科目每學期會更換開課清單，若貼上的修課紀錄裡有課名對不到（例如別學期才開的課），該筆會被列為「未辨識」，需自行手動勾選
- 體育課（0學分必修）未收錄在資料庫中，貼上匯入時會顯示未辨識，可忽略

## 技術

純前端單一 HTML 檔案（HTML + CSS + JavaScript），沒有後端、沒有資料庫，透過 GitHub Pages 託管。
