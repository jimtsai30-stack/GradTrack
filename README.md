# GradTrack｜資訊管理學系畢業學分規劃工具

長庚大學資訊管理學系（112 學年度入學適用）的畢業學分追蹤工具。單一 HTML 檔案、不需安裝、不需伺服器，打開就能用。

## 功能

- **課程勾選追蹤**：依大一到大四各學期列出系訂必修、系選修（五大領域）、管院共構必修/選修、通識課程，勾選已修課程即可。
- **即時學分統計**：總學分進度（128 學分）、各分類進度條，以及細項規則檢查（例如系選修系內至少 27 學分、通識各領域至少學分數、多元選修需涵蓋 3 個領域等），未達標會直接列出還缺哪個領域。
- **批次匯入**：把教務系統匯出的修課紀錄整段貼上，一鍵自動比對並勾選課程，比對不到的行會列出來讓你手動處理。匯入比對會自動處理常見的複製貼上問題（全形/半形、大小寫、隱藏的零寬字元等）。
- **課程搜尋**：即時篩選課表，快速找到特定課程。
- **匯出／匯入備份**：把目前的勾選狀態匯出成 JSON 檔案，換瀏覽器或換裝置時可以匯入回來還原進度。
- **深色模式**：自動跟隨系統/瀏覽器的深色模式設定。

## 使用方式

線上開啟 `https://jimtsai30-stack.github.io/degree-progress-tracker/gradtrack.html` 用瀏覽器打開即可。

## 資料儲存與隱私

所有勾選紀錄與設定只存在你目前使用的瀏覽器本機（`localStorage`），不會上傳到任何伺服器。這代表：

- 關閉分頁或瀏覽器不會遺失資料，重新打開會自動還原上次的進度。
- 換裝置或換瀏覽器**不會自動同步**，請用內建的「匯出備份／匯入備份」功能搬移資料。
- 清除瀏覽器資料會讓進度歸零，建議定期匯出備份。

## 免責聲明

課程資料整理自系課表與通識課程表 PDF，僅供自我規劃參考，**實際畢業資格審核以系辦公告與教務系統為準**。部分課程的學分數、分類歸屬（例如管院共構選修是否計入系選修外系學分上限）若與正式規定不同，請自行修改或向系辦確認。
